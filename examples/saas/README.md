# SaaS / app chrome overlay (example)

Keep marketing density off settings and billing.

- Surface `app` for account/settings; `data` for usage tables; `form` for checkout.
- Dark-anchor and L-spread apply to the **marketing** landing, not every admin page.
- Reuse one button/input/dialog. No second dashboard kit.
- If the operator seeds two shades, derive ink; do not color headings with `--primary`.
