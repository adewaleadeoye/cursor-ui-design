# Example — admin dashboard

This is an **example**, not a brand. Do **not** run a marketing craft pass here unless asked.

## Surfaces

- Reports, tables, filters: `data` — compact, sticky header, filters above the grid.
- Settings: `app`.
- Login: `form`.

## Chrome

Reuse the app button/input/table. Visible focus. No hover-scale. No decorative grain on data grids.

## Color

Stay on the product token freeze. L-spread and dark-anchor are for marketing homepages, not for every admin table.
